Project Goal Summary

CSS Property Type Validator aims to make typed CSS custom properties practical to adopt and maintain by conservatively catching invalid @property registrations and incompatible var() usage before mistakes ship. The goal emphasizes a shared validation core, consistent integrations across CLI, Stylelint, VS Code-compatible editors, and browser UI, reviewable generated registrations, stable machine-readable diagnostics, real-world token architectures, low false positives, explicit configuration, and an auditable Node.js 22+ package workflow.
